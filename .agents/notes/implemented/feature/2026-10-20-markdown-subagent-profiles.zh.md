# Agent Note: Markdown 子代理配置与原生模型回退

Status: implemented

[English](2026-10-20-markdown-subagent-profiles.md) | 中文

## 问题

用户以 Markdown 文件维护 Pi 子代理定义，需要在 Harness 中使用同样的委派工作流，不依赖 Pi、Paseo 或其他 agent 可执行程序。现有原生子代理提供生命周期、预设、继续执行和模型路由，但缺少 Markdown 发现和有序跨提供方回退。

## 决定

一个按需启用的 [Host 插件](../../../../packages/subagent/tool-subagent-profiles/README.zh.md) 负责发现、配置快照、路由以及单任务/并行/链/继续执行输入。它使用受管理的全新本地子级，而非另建编排系统，不改变 agent loop 或默认组合包。

用户定义来自 `$DSH_HOME/agents/*.md` 或操作者显式目录，可有意指向现有 Pi 目录。项目 `.dsh/agents/*.md` 发现要求操作者启用，限定在原始项目内，并拒绝符号链接逃逸。新工作重新读取定义。额外 Pi 元数据产生诊断，不声称支持不存在的能力；实际工具、提供方、凭据和推理强度仍由 Harness 提供。

原生管理器提供已注册子级初始化，携带隔离的启动 JSON 与初始化取消信号。初始化在原生组合后、发布前执行。版本 4 子级描述符保存必需初始化键；普通子级保留版本 3 描述符。处理器缺失或被替换时拒绝初始化。配置快照是独立的必需 Session 事件，因此冷恢复不重读已变化的 Markdown。配置的基础预设通过原生预设机制挂载；省略时保留原生父级组合行为，包括冷恢复时使用父级当前组合。

完整作用域工具限制通过现有注册表按需启用。它约束继承和本地能力、后续注册以及原生/嵌套 PTC 执行，不改变旧有的自身作用域豁免。配置不能授予缺失工具。空列表拒绝所有最终能力工具，同时保留 PTC 传输设施。

现有提供方重试执行器独占恢复准入和延迟。多模型配置仅在持久化重试开始依据出现后前进一步，保留同一个子级 Session 与已完成工具结果，并在下次请求前记录选定路由。策略或显式链耗尽即终止；单模型配置保留普通重试。取消、凭据/身份验证失败、配置/准备失败、工具错误以及包含错误样式文本的成功回答均不推进路由。路由使用已注册的 Harness 提供方/模型 id；仅识别出的末尾后缀表示推理强度，其他模型 id 冒号保持字面含义。冷恢复在发布前校验选定路由，普通准备过程通过实时适配器校验每次请求。

单任务和并行模式确认原生子级 id，并使用原生完成通知。完整预检先于分发；并行启动竞态保留成功兄弟任务的 id。链使用调用方交付，等待成功最终文本，替换 `{previous}`，并在失败、不完整输出或取消后停止，不启动后续条目。原生继续执行要求确切父级与记录的配置身份，保留日志目录并拒绝新 `cwd`。插件卸载取消调用，并仅等待其所属子级结束；提供方卸载移除工具，不移除恢复支持。

## 考虑过的替代方案

**在外部调用 Pi 或 Paseo。** 这保留独立运行时、凭据、进程和继续执行依赖，违背仅由 Harness 执行的要求。

**为每个角色要求 YAML 预设。** 原生预设仍是基础组合机制，但单独使用既不保留 Markdown 工作流，也不提供有序回退与链输入。

**在其他模型上替换失败子级。** 重新启动会失去稳定继续执行身份，并可能重复已完成工具。路由切换改为在既有 Session 内进行。

## 后果

Markdown 兼容不使工具名称、提供方别名、凭据或推理强度可移植。辅助元数据不复现 Pi 技能或扩展。配置限制能力并提供可信指令，但不是独立进程安全沙箱。

回退可能失去提供方 KV Cache 复用并增加计费请求。保留同一个 Session 避免主动重放工具，但不能确认未知网络结果后提供方工作的恰好一次执行。链不提供自动崩溃恢复。外部运行器、调度、新 UI、设置迁移以及完整 Pi 兼容层不属于本插件。

必需配置事件和带版本的描述符使旧读取器可以拒绝陌生子级，而非丢弃限制。针对性生命周期/权限测试、包含实际路由切换与链失败的无密钥随附 profile 快照、两个 SDK 投影以及持久化确认保留这些保证。真实提供方验证仍以密钥可用为条件。
